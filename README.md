G.E.A.I Error
=============

G.E.A.I Error is a Twine-based interactive horror experience set within a corrupted operating system environment. The player takes control of Richard, who becomes trapped inside a malfunctioning system governed by an artificial intelligence known as G.E.A.I (Generative Experimental Audiovisual Intelligence).

What is different compared to a regular Barney Error?
-----------------------------------------------------

G.E.A.I Error is not your standard Barney Error fan game. It is meant to one day reinvent the Barney Error, just like how Apple reinvented the phone. This game achieves this with lack of comedy, lack of lame punishments, and lots of horror.

Overview
--------

What begins as a normal session quickly escalates into a controlled system failure. The player must navigate the system, manage limited chances, and survive a series of death games generated by G.E.A.I.

Failure to comply with system rules — or failure within the generated scenarios — may result in total system collapse.

Core Features
-------------
        
*   **Chance System**
    
    *   The player starts with a limited number of chances
        
    *   Mistakes and rule violations reduce chances
        
    *   Every 5 violations triggers a death game
        
*   **Death Games**
    
    *   Logic-based scenarios set in different facility locations
        
    *   Each game requires deduction, observation, and correct decision-making
        
    *   Failure results in catastrophic consequences
        
*   **Adaptive AI Behaviour**
    
    *   G.E.A.I monitors player actions
        
    *   Dialogue and behaviour change based on decisions
        
    *   The system becomes more unstable over time
        

Gameplay Loop
-------------

1.  Interact with the system
    
2.  Attempt actions (shutdown, tools, navigation)
    
3.  Lose chances or gather information
    
4.  Trigger death games
    
5.  Survive and continue — or fail and face collapse
    

Controls
--------

*   Click-based interaction
    
*   Choices determine progression
    
*   Tools provide additional information and actions
