# G.E.A.I. Error

A batch-based computer horror game inspired by classic fake computer error games.

> **WARNING:** G.E.A.I. Error is a fictional game, not a real virus. It is not
> intended to damage your computer. All shutdown, restart, and other system
> failure events are simulated in-game and do not perform those actions on
> your real computer.

## ABOUT

Richard is trapped in a corrupted system by G.E.A.I., an error that refuses to be closed. With a bomb planted in the system core and a countdown of five decades, Richard must survive a series of challenges while G.E.A.I. interferes with his attempts to escape.

Your objective is to survive the error, manage your chances, and reach the final game.

## HOW TO PLAY

1. Unzip the `.7z` file and run the man `.bat` file.
2. Type `HELP` to view available commands.
3. Use `STATUS` to check your remaining chances.
4. Use survival tools strategically.
5. Complete generated tasks to avoid containment.
6. Survive until the final game.

## COMMANDS

### General commands

- `HELP` - Display available commands.
- `STATUS` - Display survival status.
- `SCAN` - Inspect simulated system diagnostics.
- `LANGUAGE` - Select a display language label.
- `TOOL` - List survival tools.
- `USE SCANNER` - Reveal diagnostic information.
- `USE FIREWALL` - Protect against one failed task.
- `USE RECOVERY` - Restore one chance.
- `WAIT` - Spend one chance.
- `PROCEED` - Spend one chance.

### Turn-off attempts

Try commands such as `SHUTDOWN`, `RESTART`, `STANDBY`, `HIBERNATE`, `LOGOFF`, `SWITCH USER`, `UNPLUG`, `BRICK`, `TASK MANAGER`, `KILL PROCESS`, `BLOCK`, `HIDE`, `CROSS OUT`, `REPLACE`, `PUNCH`, `PHONE`, `ANSWER CALL`, `SKYPE`, `CLOSE`, `ESCAPE`, and `EXIT`.

G.E.A.I. will respond to these attempts. They are fictional in-game actions and do not execute real Windows system commands.

## SURVIVAL SYSTEM

- Starting chances: 20
- Evil Mode: activates after ten chances have been spent.
- Generated tasks: occur after every five spent chances.
- Failed tasks: cause containment unless the firewall protects you.
- Final game: begins when no chances remain.

## EVIL MODE

G.E.A.I. becomes more aggressive as the game progresses. Turn-off attempts and interruptions may trigger additional penalties.

## SAFETY

G.E.A.I. Error is a fictional horror simulation. Its shutdown, restart, unplugging, and other escape attempts must remain simulated. The game should not shut down, restart, log off, or damage the real computer.
